# ExportAI Product Overview

## Muc tieu

ExportAI la Chrome extension giup nguoi dung export noi dung hoi thoai tu cac nen tang AI nhu ChatGPT, Grok, Gemini thanh cac dinh dang than thien voi AI va con nguoi:

- Markdown
- JSON
- PDF
- PNG/image snapshot
- Cac dinh dang mo rong trong tuong lai: DOCX, HTML, ZIP archive, dataset JSONL

San pham khong chi la nut "export ngay", ma la mot he thong quan ly export gom:

- Floating UI tren trang chat
- Popup extension
- Export task queue
- Export manager
- History/archive
- Preset/template
- Free/Pro gating
- AI repair system de khac phuc khi cac website AI thay doi DOM

## Doi tuong nguoi dung

- Nguoi dung AI hang ngay can luu lai hoi thoai quan trong.
- Researcher can archive prompts/responses co cau truc.
- Content creator can chuyen chat thanh Markdown/PDF.
- Developer can luu debug session, code discussion, product spec.
- Team/agency can export va chia se transcript voi khach hang.

## Gia tri cot loi

1. Export nhanh trong khi dang chat, khong lam gian doan flow.
2. File dau ra sach, co cau truc, dung duoc lai voi AI.
3. Quan ly lich su export va task ro rang.
4. Co fallback khi website thay doi giao dien.
5. Co mo hinh Free/Pro de thu tien hop ly.

## Nen tang ho tro ban dau

- ChatGPT: `chatgpt.com`, `chat.openai.com`
- Grok: `grok.com`, `x.com/i/grok`
- Gemini: `gemini.google.com`
- Perplexity: `perplexity.ai`
- Claude: `claude.ai`
- Copilot: `copilot.microsoft.com`, `bing.com/chat`
- Devin: `devin.ai`, `app.devin.ai`
- Lovable: `lovable.dev`

## Dinh dang ho tro ban dau

- Markdown: file doc chinh cho AI va con nguoi.
- JSON: schema chuan de dung cho automation, dataset, import/export.
- PDF: ban in sach, co footer/signature theo plan.
- PNG: snapshot transcript text hoac visual capture.

## Nguyen tac san pham

- Mac dinh rieng tu: khong gui transcript len server neu user chua dong y.
- Free van dung tot, Pro mo khoa nang cao.
- Khong dua logic fragile vao mot cho; moi platform co adapter rieng.
- Uu tien remote config hon remote code de an toan voi Chrome extension policy.
- Moi export nen co task record de debug, retry, va quan ly.
