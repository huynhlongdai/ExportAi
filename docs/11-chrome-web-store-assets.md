## Required Assets

| Asset | Size / format | Notes |
| --- | --- | --- |

## Screenshot Set

1. Floating export tool on a live chat page.
2. Format picker with Markdown, JSON, Word, PDF, HTML, PNG.
3. Manager Dashboard with task counts, adapter health, and server status.
4. Diagnostics detail panel with private upload and repair actions.
5. Archive re-export view with Word/HTML/JSON options.

## Copy Points

- Local-first AI chat archive.
- Export to AI-ready formats: Markdown, JSON, JSONL, CSV/TSV, HTML, PDF, PNG, Word.
- Supports provider-specific versions and a universal extension.
- Optional private diagnostics for adapter repair.
- Remote adapter updates are selector-only; no remote JavaScript execution.
- Free plan includes watermark/signature and quotas; Pro removes limits/signature and unlocks automation/custom presets.

## Privacy Disclosure

- Conversation content is captured locally for export.
- Diagnostics are local by default.
- Private diagnostic upload sends selector counts, DOM signature, hashes, and adapter metadata.
- Debug/support upload requires explicit user action.
- License validation sends the license key to the configured server.

## Review Notes

- Avoid claiming official affiliation with AI providers.
- Avoid using provider logos unless usage rights are confirmed.
- Keep screenshots free of private user transcripts.
- Ensure the extension permissions match each provider-specific listing.
